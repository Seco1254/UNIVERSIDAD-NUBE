Idea 1 · factoriales

El criterio del cociente (el «test del radio» del profesor)

En una geométrica, cada término es el anterior multiplicado por la misma razón r, y converge si |r| < 1 (M2). El cociente mira si tu serie se comporta así al final: divide cada término entre el anterior y mira a qué se acerca esa razón. Si se acerca a un L menor que 1, al final cada término es más o menos L veces el anterior: la serie se porta como una geométrica que converge.

La regla

Calcula L = limn→∞ |an+1an|.

L < 1 → converge (absolutamente).
L > 1 (o L = ∞) → diverge.
L = 1 → no dice nada: usa otro criterio.
  1. Escribe an+1: cambia cada n por (n + 1), con paréntesis, también en los exponentes y en los factoriales.
  2. Arma el cociente: dividir entre an es multiplicar por an volteada.
  3. Simplifica: las potencias de la misma base se restan los exponentes, y los factoriales se cancelan casi completos.
  4. Calcula L, compáralo con 1 y escribe la frase.
Para simplificar
  • (n + 2)! = (n + 2)·(n + 1)!, así que (n + 1)!/(n + 2)! = 1/(n + 2).
  • (n + 1)!/n! = n + 1.
  • 2n/2n−1 = 2n−(n−1) = 2 y 42n+3/42n+1 = 4² = 16.
Ejemplo resuelto 1 · Parcial 2023-19 P1b (6 pts)

Factorial abajo: converge

Determine si la serie converge o diverge: ∞Σn=0 2n−1(n + 1)!.

  1. Busca la señal.

    Hay un factorial. Con factoriales, comparar es difícil; el cociente los cancela casi completos.

    (n + 1)! abajo→criterio del cociente

  2. Escribe an y an+1.

    Cambias cada n por (n + 1): el exponente queda (n + 1) − 1 = n, y el factorial, ((n + 1) + 1)! = (n + 2)!.

    an = 2n−1(n + 1)!→an+1 = 2n(n + 2)!

  3. Arma el cociente.

    Dividir entre an es multiplicar por an volteada. Todos los términos son positivos, así que el valor absoluto no cambia nada.

    an+1an = 2n(n + 2)!·(n + 1)!2n−1 = 2n2n−1·(n + 1)!(n + 2)!

  4. Simplifica las potencias de 2.

    Misma base: se restan los exponentes, n − (n − 1) = 1. Es el ejemplo 3 de M1.

    2n2n−1 = 21 = 2

  5. Simplifica los factoriales.

    (n + 2)! es (n + 1)! multiplicado por el último factor, n + 2. El (n + 1)! se cancela.

    (n + 1)!(n + 2)! = (n + 1)!(n + 2)·(n + 1)! = 1n + 2

  6. Calcula L.

    Un número fijo entre algo que crece tiende a 0.

    L = limn→∞ 2·1n + 2 = limn→∞ 2n + 2 = 0

  7. Compara con 1 y escribe la frase.

    Como L = lim |an+1/an| = lim 2/(n + 2) = 0 < 1, por el criterio del cociente la serie converge (absolutamente).
Resultado: converge.

¿Tiene sentido? El factorial le gana a cualquier potencia como 2n (la escalera de M1): cada término es mucho más pequeño que el anterior. Que la suma empiece en n = 0 no cambia nada.

Ejemplo resuelto 2 · Hoja 11.6 (g) · con la trampa 1∞

Factorial contra nn: el cociente da 1/e

Determine si la serie converge o diverge: ∞Σn=1 n!nn.

  1. Busca la señal.

    Hay un factorial arriba: cociente.

    n! arriba→criterio del cociente

  2. Escribe an+1.

    Cambias cada n por (n + 1), también la base y el exponente de abajo.

    an = n!nn→an+1 = (n + 1)!(n + 1)n+1

  3. Arma el cociente.

    Multiplicas por an volteada y juntas factoriales con factoriales.

    an+1an = (n + 1)!(n + 1)n+1·nnn! = (n + 1)!n!·nn(n + 1)n+1

  4. Simplifica los factoriales.

    (n + 1)! es n! por el último factor, n + 1.

    (n + 1)·n!n! = n + 1

  5. Simplifica las potencias de (n + 1).

    (n + 1)n+1 es (n + 1)n por un (n + 1) más. Ese (n + 1) se cancela con el que dejaron los factoriales.

    (n + 1)·nn(n + 1)·(n + 1)n = nn(n + 1)n = (nn + 1)n

  6. Reconoce la trampa 1∞.

    La base n/(n + 1) tiende a 1 y el exponente a ∞. No es 1 (M1, ejemplo 5): voltea la fracción para que quede la regla del número e.

    (nn + 1)n = 1(n + 1n)n = 1(1 + 1n)n

  7. Calcula L.

    (1 + 1/n)n → e1 = e (regla del número e con a = 1).

    L = limn→∞ 1(1 + 1/n)n = 1e ≈ 0,37

  8. Compara con 1 y escribe la frase.

    Como L = lim |an+1/an| = lim (n/(n + 1))n = 1/e ≈ 0,37 < 1, por el criterio del cociente la serie converge.
Resultado: converge.

¿Tiene sentido? nn = n·n·…·n tiene n factores iguales a n, y n! = 1·2·…·n tiene factores más pequeños: abajo crece más rápido (en la escalera de M1, nn está a la derecha de n!). Si escribes «la base tiende a 1, así que L = 1 y no se puede decidir», pierdes el punto.

Idea 2 · todo elevado a la n

El criterio de la raíz

Si el término entero está elevado a la n, como (algo)n, sacarle la raíz n-ésima deshace el exponente y deja solo «el algo». Si «el algo» se acerca a un L menor que 1, el término se parece a Ln: una geométrica que converge.

La regla

Calcula L = limn→∞ |an|1/n. Las conclusiones son las mismas del cociente: L < 1 converge (absolutamente), L > 1 diverge y L = 1 no dice nada.

Para simplificar: los exponentes se multiplican
  • (algon)1/n = algon·(1/n) = algo: el exponente desaparece.
  • (algon²)1/n = algon²/n = algon: el exponente no desaparece, baja de n² a n.
  • (algo5n)1/n = algo5.
Ejemplo resuelto 3 · Parcial 2023-19 P1d (6 pts)

Todo elevado a la n: diverge

Determine si la serie converge o diverge: ∞Σn=0 (2n²n² + 3)n.

  1. Busca la señal.

    Todo el término está elevado a la n: la raíz n-ésima lo deshace.

    (…)n→criterio de la raíz

  2. Saca la raíz n-ésima.

    El término es positivo, así que |an| = an. Los exponentes se multiplican: n·(1/n) = 1.

    |an|1/n = [(2n²n² + 3)n]1/n = (2n²n² + 3)n·(1/n) = 2n²n² + 3

  3. Calcula L.

    Mismo grado arriba y abajo: divides todo entre n² (M1, ejemplo 1).

    L = limn→∞ 2n²n² + 3 = limn→∞ 21 + 3/n² = 21 + 0 = 2

  4. Compara con 1 y escribe la frase.

    Como L = lim |an|1/n = lim 2n²/(n² + 3) = 2 > 1, por el criterio de la raíz la serie diverge.
Resultado: diverge.

¿Tiene sentido? El término se parece a 2n, que crece sin parar: ni siquiera tiende a 0. Siempre que la raíz o el cociente dan L > 1, el término no tiende a 0.

Ejemplo resuelto 4 · Parcial 2025-10 P1b (6 pts)

Elevado a n²: la raíz da e²

Determine si la serie converge o diverge: ∞Σn=1 (n + 2n)n².

  1. Busca la señal.

    Todo el término está elevado a n²: raíz.

    (…)n²→criterio de la raíz

  2. Saca la raíz n-ésima.

    Los exponentes se multiplican: n²·(1/n) = n. El exponente no desaparece, baja de n² a n. Esta es la diferencia con el ejemplo anterior.

    |an|1/n = [(n + 2n)n²]1/n = (n + 2n)n²/n = (n + 2n)n

  3. Reescribe la base.

    Partes la fracción en dos y simplificas n/n (M1, ejemplo 5).

    n + 2n = nn + 2n = 1 + 2n

  4. Reconoce la trampa 1∞ y usa la regla del número e.

    La base tiende a 1 y el exponente a ∞: no es 1. La regla (1 + a/n)n → ea con a = 2.

    L = limn→∞ (1 + 2n)n = e² ≈ 7,39

  5. Compara con 1 y escribe la frase.

    Como L = lim |an|1/n = lim (1 + 2/n)n = e² ≈ 7,39 > 1, por el criterio de la raíz la serie diverge.
Resultado: diverge.

¿Tiene sentido? La hoja 11.6 (i) es la misma serie con 1 + 1/n: L = e > 1, diverge. El profesor tomó el ejercicio de la hoja y cambió el 1 por un 2. Quien escribe «la base tiende a 1, así que L = 1» pierde los 6 puntos.

Idea 3 · cuándo no usarlos

Si L = 1, el criterio no dice nada

Serie|an+1/an|L¿Qué hace la serie?
Σ 1/nn/(n + 1)1Diverge (serie p, p = 1)
Σ 1/n²n²/(n + 1)²1Converge (serie p, p = 2)
Σ n/(2n³ + 1) (hoja 11.4 a)…1Converge (M3: compara con 1/n²)

Las dos primeras dan L = 1 y hacen cosas distintas: por eso con L = 1 no se concluye nada. Pasa siempre con las fracciones de potencias de n, las de M3: el cociente y la raíz dan 1. Ahí no pierdas tiempo; compara con una serie p desde el principio. El cociente y la raíz sirven cuando hay factoriales o algo elevado a la n.

Idea 4 · signos que alternan

Series alternantes: absoluta, condicional o diverge

Una serie alternante suma y resta: b1 − b2 + b3 − b4 + … Las sumas parciales van en zigzag: suben, bajan, suben. Si cada paso es más corto que el anterior (bn decrece) y los pasos se encogen hasta 0 (bn → 0), el zigzag se va cerrando sobre un número: la serie converge. Lo ves en el lab.

Criterio de series alternantes (Leibniz)

Si la serie es Σ (−1)n·bn (o con (−1)n+1), con bn > 0, y además

  • (i) bn es decreciente: bn+1 ≤ bn, al menos desde algún n en adelante, y
  • (ii) limn→∞ bn = 0,

entonces la serie converge.

Cómo probar que bn decrece: cambia n por x y deriva. Si f′(x) < 0 desde algún x, bn decrece desde ahí. Para fracciones usas la regla del cociente de Cálculo 1: (u/v)′ = (u′·v − u·v′)/v².

Converge absolutamente: Σ |an| converge. Entonces Σ an también converge.
Converge condicionalmente: Σ an converge, pero Σ |an| diverge. Converge gracias a los signos.
Diverge: Σ an diverge.

La receta para una serie con (−1)n

  1. ¿|an| tiende a 0? Si no, diverge por el criterio de divergencia (M2) y ya. Leibniz no aplica.
  2. Quita el signo: estudia Σ |an| con M3 (comparación) o con cociente o raíz. Si converge, la serie converge absolutamente y terminaste.
  3. Si Σ |an| diverge, usa Leibniz: bn decreciente (con la derivada) y bn → 0. Si cumple, la serie converge condicionalmente.
Ejemplo resuelto 5 · Parcial 2023-19 P1c (6 pts)

Alternante que converge condicionalmente

Determine si la serie converge o diverge: ∞Σn=2 (−1)n 2nn² + 1.

  1. Busca la señal y separa bn.

    El (−1)n la hace alternante. bn es lo que queda sin el signo, y es positivo.

    an = (−1)n·2nn² + 1→bn = 2nn² + 1 > 0

  2. Paso 1 de la receta: ¿bn tiende a 0?

    Grado 1 arriba y grado 2 abajo: divides entre n² (M1).

    limn→∞ 2nn² + 1 = limn→∞ 2/n1 + 1/n² = 01 = 0→sigue

  3. Paso 2: quita el signo y compara (M3).

    Términos dominantes: 2n/n² = 2/n, así que comparas con 1/n. Dividir entre 1/n es multiplicar por n.

    L = limn→∞ 2nn² + 1·n = limn→∞ 2n²n² + 1 = 2yΣ 1n diverge

  4. Concluye el paso 2.

    L = 2 es finito y positivo, así que Σ |an| hace lo mismo que la armónica: diverge. No es absoluta, pero eso no dice que la serie diverja: falta Leibniz.

    Σ |an| = Σ 2nn² + 1 diverge

  5. Paso 3, Leibniz (i): deriva para ver si bn decrece.

    Cambias n por x y usas la regla del cociente con u = 2x (u′ = 2) y v = x² + 1 (v′ = 2x).

    f(x) = 2xx² + 1→f′(x) = 2·(x² + 1) − 2x·2x(x² + 1)² = 2 − 2x²(x² + 1)²

  6. Mira el signo de la derivada.

    Abajo hay un cuadrado: siempre positivo. Arriba, 2 − 2x² es negativo cuando x² > 1, o sea x > 1. La serie empieza en n = 2, así que bn decrece en todos sus términos.

    x > 1 ⇒ 2 − 2x² < 0 ⇒ f′(x) < 0 ✓

  7. Leibniz (ii): bn → 0.

    Ya lo calculaste en el paso 1.

    limn→∞ bn = 0 ✓

  8. Escribe la frase.

    La serie es alternante con bn = 2n/(n² + 1) > 0, que es decreciente para n ≥ 2 (f′(x) < 0 para x > 1) y tiende a 0. Por el criterio de series alternantes, la serie converge. Como Σ |an| diverge (comparación en el límite con Σ 1/n, L = 2), la serie converge condicionalmente.
Resultado: converge (condicionalmente).

¿Tiene sentido? Sin los signos se parece a 2/n, que diverge. Con los signos, cada término cancela casi todo el anterior, como en 1 − 1/2 + 1/3 − 1/4 + …, que converge a ln 2 (míralo en el lab). En 2023 solo preguntaban «converge o diverge», así que con Leibniz bastaba; pero si preguntan «absoluta o condicional», como la hoja 11.6, hace falta el paso 2.

Ejemplo resuelto 6 · Hoja 11.6 (e)

Alternante que converge absolutamente

Determine si la serie converge absolutamente, condicionalmente o diverge: ∞Σn=1 (−1)n arctan(n)n².

  1. Busca la señal y quita el signo.

    Hay (−1)n: primero se prueba el valor absoluto. Para n ≥ 1, arctan n es positivo.

    |an| = arctan(n)n²

  2. Acota el arctan.

    El arctan nunca pasa de π/2 ≈ 1,57, su techo (M1). Divides entre n², que es positivo, así que las desigualdades no se voltean.

    0 < arctan n < π2⇒0 < arctan(n)n² < π/2n²

  3. Decide la serie de la derecha.

    Es π/2 por una serie p con p = 2. Multiplicar por un número fijo no cambia si converge.

    Σ π/2n² = π2·Σ 1n²: p = 2 > 1, converge

  4. Escribe la frase.

    Como 0 < |an| = arctan(n)/n² < (π/2)/n² y Σ (π/2)/n² converge (serie p con p = 2), Σ |an| converge por comparación directa. Entonces la serie converge absolutamente.
Resultado: converge absolutamente.

¿Tiene sentido? Cuando la serie converge absolutamente, ya terminaste: no hace falta Leibniz. Por eso conviene probar primero |an|.

Idea 5 · la estrategia del punto 1

¿Qué criterio uso?

Lo difícil del punto 1 no es la cuenta: es escoger el criterio. Mira la forma del término y recorre esta lista en orden. En cuanto una respuesta sea «sí», ese es tu criterio.

  1. ¿El término no tiende a 0?Diverge. Criterio de divergencia (M2).Σ n/(2n + 1): el término tiende a 1/2 ≠ 0, así que diverge. Ese 1/2 no es la suma.
  2. ¿Es geométrica o serie p?Se decide de una: |r| < 1 o p > 1 (M2, M3).Σ 3·(2/5)n, Σ 1/n3/2.
  3. ¿Todo está elevado a n o a n²?Raíz.2023 P1d (2n²/(n² + 3))n · 2025 P1b ((n + 2)/n)n².
  4. ¿Hay factoriales, o cn junto a potencias de n?Cociente.2023 P1b 2n−1/(n + 1)! · hoja 11.6 (c) y (d).
  5. ¿Tiene (−1)n?Primero Σ |an|; si diverge, Leibniz.2023 P1c. Para Σ |an| vuelves a recorrer esta lista.
  6. ¿Tiene sen n, cos n o arctan n?Acota y usa comparación directa (M3).2023 P1e sen² n/n³ · 2025 P1c (1 + sen² n)/n.
  7. ¿Es una fracción con potencias o raíces de n?Comparación en el límite con 1/np (M3).2023 P1a √(n + 1)/(n + 2) · 2025 P1a √(n³ + 5)/(n³ − 3).

Si te piden el valor de la suma (no solo si converge), es telescópica o geométrica: M2, como el 2025 P2.

Las frases para el parcial

CriterioLo que escribes
DivergenciaComo lim an = … ≠ 0, la serie diverge por el criterio de divergencia.
CocienteComo L = lim |an+1/an| = … < 1, la serie converge (absolutamente) por el criterio del cociente. (Con L > 1: diverge.)
RaízComo L = lim |an|1/n = … > 1, la serie diverge por el criterio de la raíz. (Con L < 1: converge absolutamente.)
LeibnizLa serie es alternante con bn = … > 0, que es decreciente (f′(x) < 0 para x > …) y tiende a 0. Por el criterio de series alternantes, la serie converge.
AbsolutaComo Σ |an| converge (por …), la serie converge absolutamente.
CondicionalLa serie converge por Leibniz, pero Σ |an| diverge (por …): converge condicionalmente.
ComparacionesLas de M3.

Trampas

L = 1 no dice nada. Las fracciones de potencias de n siempre dan 1: ahí usa comparación (M3) desde el principio.

1∞ no es 1: (1 + 2/n)n → e² y (n/(n + 1))n → 1/e. Es la que costó el 2025 P1b.

(algon²)1/n = algon, no «algo»: el exponente baja de n² a n.

Simplifica con cuidado: (n + 2)! = (n + 2)·(n + 1)!, y 42(n+1)+1 = 42n+3.

Que Σ |an| diverja no significa que la serie diverja: solo que no es absoluta. Falta Leibniz.

Leibniz pide dos cosas: decreciente y que tienda a 0. Si bn crece al principio, no importa: basta desde algún n.

El límite del término no es la suma: si an → 1/2, la serie diverge; no «vale 1/2».

«Test del radio» es el cociente. Así lo llama el profesor; no es el radio de convergencia de M6, aunque allá lo vas a usar para hallarlo.
