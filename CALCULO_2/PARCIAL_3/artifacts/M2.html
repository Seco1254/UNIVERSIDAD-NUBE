Idea 1

Qué es una serie y qué quiere decir que converja

Una serie es una suma infinita. No se puede sumar todo de una vez, así que se suma por partes: la suma parcial SN suma los primeros N términos. Si SN se acerca a un número S cuando N crece, la serie converge y vale S. Si no, diverge. Mira Σn≥1 1/2n:

NSNLo que falta para 1
11/21/2
21/2 + 1/4 = 3/41/4
33/4 + 1/8 = 7/81/8
47/8 + 1/16 = 15/161/16

Cada vez falta la mitad de lo que faltaba: SN = 1 − 1/2N → 1. La serie converge y vale 1.

No confundas el término con la suma

En Σ 1/2n, los términos 1/2n tienden a 0 y las sumas parciales tienden a 1. La serie vale 1, no 0. El término y la suma son dos sucesiones distintas.

Idea 2 · extremos de la serie de potencias

El criterio de divergencia

La regla

Si limn→∞ an ≠ 0 (o no existe), la serie Σ an diverge.

Si el límite es 0, este criterio no dice nada: hay que usar otro (M3 y M4).

Por qué funciona: si los términos no se achican hasta 0, cada vez le estás sumando algo de tamaño fijo a la suma, y la suma no se puede quedar quieta.

Ejemplo resuelto 1 · Hoja 11.2 (5a)

Mostrar que una serie diverge

Muestra que ∞Σn=1 nn + 1 diverge.

  1. Calcula el límite del término.

    Es un cociente con el mismo grado arriba y abajo (M1): el límite es el cociente de los números que acompañan a n.

    limn→∞ nn + 1 = limn→∞ 11 + 1n = 1

  2. Compáralo con 0.

    El límite es 1, no 0: los términos no se achican.

    1 ≠ 0

  3. Concluye con una frase.

    En el parcial, sin la frase no hay puntos.

    Como lim n/(n + 1) = 1 ≠ 0, la serie diverge por el criterio de divergencia.
Resultado: diverge.

¿Tiene sentido? Desde cierto n, cada término vale casi 1, así que SN crece más o menos como N. Lo ves en el lab.

La armónica: el término tiende a 0 y aun así diverge

Σ 1/n diverge aunque 1/n → 0. Agrupa los términos: 1 + 1/2 + (1/3 + 1/4) + (1/5 + 1/6 + 1/7 + 1/8) + … Cada paréntesis suma por lo menos 1/2 (por ejemplo, 1/3 + 1/4 ≥ 1/4 + 1/4 = 1/2). Sumar 1/2 infinitas veces da infinito.

Por eso el criterio de divergencia solo sirve para decir diverge, nunca para decir converge.

Idea 3 · P2 y molde de Taylor

La serie geométrica

La regla

Una serie es geométrica si cada término se obtiene multiplicando el anterior por el mismo número r, la razón.

Converge si |r| < 1, y entonces vale primer término1 − r. Si |r| ≥ 1, diverge.

Para encontrar r, escribe todo lo que tiene n como (algo)n: ese «algo» es la razón. El primer término se saca reemplazando el índice de abajo.

Ejemplo resuelto 2 · Hoja 11.2 (2e)

Sumar una geométrica

Decide si converge y encuentra su valor: ∞Σn=0 2n3n+1.

  1. Separa la potencia de 3.

    3n+1 = 3·3n. Así todo lo que tiene n queda junto.

    2n3n+1 = 2n3·3n = 13·(23)n

  2. Identifica la razón.

    Lo que está elevado a la n es la razón.

    r = 23y|r| < 1→converge

  3. Calcula el primer término.

    La suma empieza en n = 0: reemplaza n = 0. Cualquier número a la 0 es 1.

    13·(23)0 = 13

  4. Usa la fórmula.

    S = 1/31 − 2/3 = 1/31/3 = 1
Resultado: converge y vale 1.

¿Tiene sentido? S1 = 1/3, S2 = 1/3 + 2/9 = 5/9 y S3 = 5/9 + 4/27 = 19/27 ≈ 0,70: se van acercando a 1. Lo ves en el lab.

Ejemplo resuelto 3 · Hoja 11.2 (2b) · la trampa del primer término

Cuando el primer término no es el que parece

Encuentra el valor de ∞Σn=0 12n−1.

  1. Identifica la razón.

    1/2n−1 = (1/2)n−1: cada término es la mitad del anterior.

    r = 12y|r| < 1→converge

  2. Calcula el primer término reemplazando n = 0.

    Aquí está la trampa: con n = 0 el exponente es −1, y un exponente negativo voltea la fracción.

    120−1 = 12−1 = 2

  3. Usa la fórmula.

    S = 21 − 1/2 = 21/2 = 4
Resultado: converge y vale 4.

¿Tiene sentido? Es 2 + 1 + 1/2 + 1/4 + … = 4. Si hubieras puesto 1 como primer término, te daría 2: esa es la serie que empieza en n = 1 (hoja 11.2 (2a)).

Idea 4 · el puente a M6 y M7

Geométrica con x

Si la razón tiene una x, la serie converge solo para los x que hacen |r| < 1. Esa es la idea de una serie de potencias (M6), y al revés, escribir una función como una serie así es lo que pide la Taylor del parcial (M7).

Ejemplo resuelto 4 · Hoja 11.2 (4d)

¿Para qué x converge?

Encuentra los valores de x para los que converge ∞Σn=0 (x + 25)n, y su suma.

  1. Identifica la razón.

    r = x + 25

  2. Pide |r| < 1 y despeja x.

    |algo| < 1 quiere decir que ese algo está entre −1 y 1. Multiplicas todo por 5 y después le restas 2 a las tres partes.

    −1 < x + 25 < 1→−5 < x + 2 < 5→−7 < x < 3

  3. Calcula la suma.

    El primer término (n = 0) es 1. Para simplificar, multiplicas arriba y abajo por 5.

    S = 11 − x + 25 = 55 − x − 2 = 53 − x
Resultado: converge para −7 < x < 3, y ahí vale 5/(3 − x).

¿Tiene sentido? En los extremos, x = −7 y x = 3, la razón vale −1 y 1: el término no tiende a 0 y la serie diverge (idea 2). Leída al revés, la igualdad dice 5/(3 − x) = Σ ((x + 2)/5)n: una función escrita como serie, que es exactamente lo que harás en M7.

Idea 5 · el P2 de 2025 (7 pts)

La serie telescópica

Una serie es telescópica cuando cada término se puede escribir como una resta en la que un pedazo se cancela con el término siguiente. Las sumas parciales se encogen como un telescopio y queda una fórmula corta para SN.

  1. Factoriza el denominador.
  2. Fracciones parciales: escribe el término como una resta.
  3. Escribe SN con los primeros términos y el último, y tacha lo que se cancela.
  4. Toma el límite de SN. Si existe, la serie converge y ese es su valor.
Ejemplo resuelto 5 · Parcial 2025-10 P2 (7 pts)

Muestre que la serie converge y encuentre su valor

∞Σk=1 2k² + k

  1. Factoriza el denominador.

    k es factor común.

    k² + k = k(k + 1)

  2. Escribe el término como resta (fracciones parciales).

    Buscas A y B con 2/(k(k + 1)) = A/k + B/(k + 1). Multiplicando por k(k + 1) queda 2 = A(k + 1) + B·k. Con k = 0 sale A = 2; con k = −1 sale B = −2.

    2k(k + 1) = 2k − 2k + 1

  3. Escribe SN y tacha.

    Pones los primeros términos y el último. El −2/2 del primero se cancela con el +2/2 del segundo, el −2/3 con el +2/3, y así hasta el final.

    SN = (21 − 22) + (22 − 23) + (23 − 24) + … + (2N − 2N + 1)

  4. Escribe lo que sobrevive.

    Solo quedan el primer pedazo y el último.

    SN = 2 − 2N + 1

  5. Toma el límite.

    2/(N + 1) → 0 porque el 2 queda fijo y N + 1 crece.

    limN→∞ SN = 2 − 0 = 2
Resultado: converge y vale 2. En el parcial se escribe: «Como SN = 2 − 2/(N + 1) → 2, la serie converge y su valor es 2».

¿Tiene sentido? S1 = 1, S2 = 4/3, S3 = 3/2: se van acercando a 2. En el lab lo ves tachándose término por término.

Cuando la resta salta más de un término

Si el término queda como 1/(k + 1) − 1/(k + 3), cada pedazo se cancela con el de dos términos más adelante, y sobreviven los dos primeros positivos. Lo practicas en el taller con la hoja 11.2 (3).

La receta del P2: ¿me piden el valor?

  1. ¿Todo lo que tiene n está elevado a la n? Es geométrica: encuentra r, revisa |r| < 1 y usa primer término/(1 − r).
  2. ¿Es una fracción con un denominador que se factoriza? Es telescópica: fracciones parciales, SN, tachar y límite.
  3. ¿Solo preguntan si converge? Empieza por el criterio de divergencia. Si el término tiende a 0, necesitas M3 o M4.

Trampas

El primer término sale del índice de abajo: Σ desde n = 0 de 1/2n−1 empieza en 2, no en 1.

Con |r| = 1 la geométrica diverge: Σ 1n y Σ (−1)n no convergen.

Que el término tienda a 0 no dice que converja: la armónica.

En la telescópica escribe varios términos y el último antes de tachar, para ver bien qué sobrevive.

«Muestre que converge» se responde con el límite de SN: sin esa frase, el profesor no da los puntos.

Reto 1 · Escoge Σ 1/n. ¿Cuánto vale SN con N = 100? ¿Y con N = 150?

≈ 5,19 y ≈ 5,59. Sube cada vez más despacio, pero nunca se detiene: diverge. Por eso no se decide «a ojo» con la calculadora.

Reto 2 · Escoge Σ rn con r = 0,9. ¿A qué se acerca? ¿Y con r = 1?

A 1/(1 − 0,9) = 10, despacio. Con r = 1 cada término vale 1, así que SN = N: diverge. Con r = −1 salta entre 1 y 0: también diverge.

Reto 3 · En la telescópica, ¿qué sobrevive con N = 5?

2/1 − 2/6 = 5/3: el primer pedazo y el último. Todo lo del medio se cancela.
